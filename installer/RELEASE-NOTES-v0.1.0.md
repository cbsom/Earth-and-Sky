# Earth & Sky v0.1.0

Explore the movement of the Sun, Moon, planets, and constellations above a rotating Earth. Earth & Sky runs offline, with Globe and Flat map views, daylight and twilight shading, a photographic Moon phase, all 88 constellations, and My Horizon for a selected location.

## Downloads

- **Windows 10/11 x64:** `Earth-and-Sky-0.1.0-Windows-x64-Setup.exe`. Run setup; Qt is included.
- **Linux Mint 22 / Ubuntu 24.04 x86_64:** `Earth-and-Sky-0.1.0-Linux-amd64.deb`. Install with `sudo apt install ./Earth-and-Sky-0.1.0-Linux-amd64.deb`.
- **Portable Linux x86_64:** `Earth-and-Sky-0.1.0-Linux-x86_64.AppImage`. Make executable using `chmod +x`, then run. Qt is included; compatible system/graphics libraries are still required.

Compiler-specific `.tar.gz` and `windows-cl.zip` files are developer builds. Choose the installer/AppImage above for normal use. Linux checksums can be verified with `sha256sum -c FILE.sha256`.

## First steps

Drag the globe to turn it; scroll to zoom. Choose Rotate Sky or Rotate Earth, select an interval, then step or animate in either direction. Click a place for My Horizon. Home city saves a startup location; Reset returns to current time and that location. Layer switches and Flat map/Globe choice are saved.

Linux packages were built on Mint 22.3 (Ubuntu 24.04 base). Older Linux, ARM64 and macOS packages have not been validated. See the repository README for installation, controls, source and attribution details.
