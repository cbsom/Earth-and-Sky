# Earth & Sky v0.1.1

Released 2026-11-08: https://github.com/cbsom/Earth-and-Sky/releases/tag/v0.1.1

- Time animation keeps the Sun or Moon centered when viewing Earth from that body.
- Other issue fixes and tweaks.
- Small version label beside the application name in the footer.
- Application, Windows file metadata, and package version updated to 0.1.1.
- GPL-3.0-or-later application licensing and bundled third-party notices, including Simplemaps city-data attribution.
- Source snapshot packaging with per-file hashes.

## Downloads

- Windows 10/11 x64: `Earth-and-Sky-0.1.1-Windows-x64-Setup.exe`.
- Linux Mint 22 / Ubuntu 24.04 x86_64: `Earth-and-Sky-0.1.1-Linux-amd64.deb`.
- Portable Linux x86_64: `Earth-and-Sky-0.1.1-Linux-x86_64.AppImage`.
- Application source: `Earth-and-Sky-0.1.1-Source.zip`, including a per-file hash manifest. Qt source and the SDK are not included.

Qt runtime libraries are included in the application packages. Linux still needs compatible system and graphics libraries. No macOS installer is provided.

The Linux packages and source ZIP have matching `.sha256` downloads. A Windows installer checksum file was not present when the release was reviewed on 2026-11-08. See [the release checklist](../RELEASE-CHECKLIST.md) for remaining verification and source-distribution tasks.
