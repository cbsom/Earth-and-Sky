# Linux packaging validation — 2026-11-04

Source: current files from `/home/chaim/Documents/Earth-and-Sky`, based on commit
`fb90df4` (Windows installer addition). Application C++/QML was not modified.
Release version: 0.1.0, matching the Inno Setup script.

Built on Linux Mint 22.3 (Ubuntu 24.04 base), x86_64, GCC 13.3 and Qt 6.8.3.

## Completed

- Fresh Release build of current source passed built-in astronomy, twilight,
  lunar phase, zodiac, navigation and globe tests.
- Bundled Qt libraries, QML imports, image plugins and XCB platform plugin with
  linuxdeploy. Added the offscreen platform for reproducible headless checks.
- AppImage passed built-in tests and rendered flat and globe views with SDK
  library/plugin/QML environment variables cleared.
- Extracted final .deb passed the same tests and both rendering checks.
- Debian package metadata includes versioned system-library dependencies,
  generated by dpkg-shlibdeps across bundled ELF files and plugins.
- Package files have root:root archive ownership; directories are world
  traversable. Application files and Qt remain private under /opt/earth-and-sky.
- Menu launcher validates with desktop-file-validate. Shell scripts pass bash -n.
- SHA-256 files use relative asset filenames.

  RPM distributions and native Wayland support have not been validated.
